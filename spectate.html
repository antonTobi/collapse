The whole game is played out headlessly the moment you pick a seed, then loaded as a replay. Scrub with the slider, step with ← and →, jump with Home and End. The outlined tile is the move the agent plays next from the position on screen. "Show move evaluations" prints every candidate move's value at the current position, so you can see what the agent rejected and by how much.

Agents marked net use the learned value function and fetch a weights file, so this page has to be served over http for them (npx serve in the repo root, then open /spectate.html). The hand-weighted agents work from a plain file:// path.
